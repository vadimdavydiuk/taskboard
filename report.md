### 2. Відповіді на запитання:

1. **Яка адреса сторінки в браузері? З яких частин вона складається?**
   Адреса: `http://127.0.0.1:5500/index.html`. Вона складається з протоколу (`http://`), IP-адреси локального сервера (`127.0.0.1`), номера порту (`5500`) та шляху до ресурсу (`/index.html`).

2. **Скільки запитів зробив браузер при завантаженні сторінки і чому саме стільки?**
   Браузер зробив 2 запити (`index.html` та іконку). Спочатку він завантажив HTML-файл, розпарсив його і знайшов тег `<img>`, після чого виконав другий запит за зображенням.

3. **Що відбулось, коли ти поставив неправильний шлях до зображення?**
   Зображення не завантажилося, з'явився альтернативний текст з `alt`, а у вкладці Network цей запит підсвітився червоним кольором зі статусом `404 Not Found`.

4. **Чому зміни, зроблені через DevTools, зникли після F5?**
   Тому що DevTools змінює лише копію сторінки в оперативній пам'яті браузера для тестування, але не змінює вихідний файл на диску.

5. **Хто в цій схемі клієнт, а хто сервер?**
   Браузер є клієнтом, а розширення Live Server у VS Code виконує роль локального веб-сервера.

### Відповіді на підсумкові запитання (Лабораторна 4):

1. **Що змінилося у виводі git status після git add?**
   Файли перемістилися до зеленого списку `Changes to be committed` (індекс), що означає їх готовність до збереження у наступному коміті.

2. **Що показує git diff?**
   Показує конкретні зміни на рівні рядків між робочою директорією та останнім комітом (додані рядки позначені `+`, а видалені `-`).

3. **Чим відрізняється git switch main від git merge?**
   `git switch main` перемикає поточну робочу гілку на гілку `main`, а `git merge` об'єднує зміни з іншої гілки в ту, на якій ти зараз перебуваєш.

4. **Чому виник конфлікт і як ти його розв'язав?**
   Конфлікт виник через те, що в гілці `main` та у гілці `ukr-title` було змінено один і той самий рядок у файлі `index.html` по-різному. Конфлікт було розв'язано вручну через редагування файлу: видалення службових міток (`<<<<<<<`, `=======`, `>>>>>>>`) та об'єднання потрібного тексту з подальшим додаванням до індексу (`git add`) і комітом.

5. **Скільки commit-ів у твоїй історії?**
   Історія містить усі зроблені коміти, включаючи створення сторінок, гілок, злиття та додавання звіту.
